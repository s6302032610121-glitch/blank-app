## 2026-02-02 - Improving Discoverability and Accessibility in Blank Templates
**Learning:** For minimal app templates, using sidebars for setup instructions significantly improves onboarding discoverability without cluttering the main UI. Also, descriptive link text (e.g., [Streamlit Documentation]) is much better for accessibility than raw URLs.
**Action:** Always include a 'Getting Started' sidebar and prioritize descriptive text for links in minimal Streamlit apps.
