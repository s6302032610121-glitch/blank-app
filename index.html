Steel Factory Building (Thailand Standard)

Code: AISC 360-16 / ACI 318-19 Date: Ref: SC-2024-001

1. Project Description

This report details the structural analysis and design for a single-storey steel industrial factory. The primary structural system consists of a portal frame with H-beam columns and rafters. Roofing is supported by C-purlins. Foundations are designed as isolated footings.
